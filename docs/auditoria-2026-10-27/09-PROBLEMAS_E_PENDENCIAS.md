## Divergências e funcionalidades órfãs

- GET /finance/receivables/:id, GET /matters/:id e GET /documents/:id não têm consumidor de UI localizado por busca estática.
- Rotas /notifications/hearing-alerts/cron e /notifications/access-alerts/cron existem, mas não aparecem no agendamento declarativo encontrado. /notifications/dispatch/cron tem scheduler separado e /notifications/cron tem cron Vercel.
- O módulo SMTP é configurado no parser, mas não tem serviço consumidor identificado.
- A interface do financeiro guarda despesas sem operações de ciclo de aprovação/pagamento.
- A auditoria é baseada no checkout local já alterado; a diferença para branch publicada pode mudar esses achados.

## Limites para classificar

Não foram reproduzidos vazamento de token em log, ataque a upload, bypass de tenancy, falha de migration, erro de e-mail, perda de push ou inconsistência de dados. Os riscos estáticos não devem ser descritos como incidentes confirmados. Para plano de resposta, ver 11-PLANO_DE_EVOLUCAO.md.
